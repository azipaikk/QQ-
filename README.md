# qqmusic-comment-card

输入一首歌的歌名，从 QQ 音乐取专辑封面和**点赞最多的热门评论**，做成 3:4 的"电影字幕"风格评论卡片：
专辑封面做主图，评论像字幕条一样一条条拼接在下方，可直接发朋友圈、小红书。

这是一个给 [Codex](https://developers.openai.com/codex) 等 Agent 使用的 skill：脚本负责取数、清理文字、断行、标记问题、渲染和质检，
Agent 负责确认是哪首歌、挑哪几条评论、怎么分组。

## 它做什么

- 搜歌并确认是哪一首（识别 Live、DJ、翻唱等衍生版本；没有原唱版权时会提醒）
- 取专辑封面（自动取可用的最大尺寸）和多页热门评论
- 清理评论文字：还原被转义的换行、去掉不可见字符和表情符号、折叠多余空格；**作者自己的换行直接变成字幕条的断行**
- 自动给评论打标记：广告推广、联系方式、表情/音频代码、占位刷屏、**整段抄歌词**（用歌词在内存里比对，歌词不保存）、
  复制粘贴的近似重复、AI 腔、可能提到具体人名
- 长评论自动列出可截取的完整句子；渲染前校验；渲染后逐字核对原文；逐张自动质检并要求肉眼复查
- **不显示、不保存评论者的任何信息**（昵称、头像、用户标识）

## 前置条件

1. Python **3.10 或更新**
2. 本机有中文字体（Windows / macOS 自带的即可）
3. 在**自己的电脑**上运行，需要能访问 `qq.com` 和 `tencentmusic.com`（网页版或受限沙箱不行）
4. 不需要 QQ 音乐账号，不需要任何 Key

第三方库（`qqmusic-api-python` 和 `Pillow`）由 skill 在征得同意后装进技能目录下的 `.deps/`，不动你电脑上已有的 Python 环境，删掉该文件夹即卸载。

## 安装（Codex）

1. 在本仓库页面点绿色 **Code** 按钮 → **Download ZIP**，解压
2. 把解压出来的 `skills/qqmusic-comment-card` 整个文件夹复制到 Codex 的技能目录：
   - Windows：`C:\Users\你的用户名\.codex\skills\`
   - macOS / Linux：`~/.codex/skills/`
3. **完全退出并重新打开 Codex**

## 使用

在 Codex 里直接说：

> 用 QQ 音乐的热评，帮我把周杰伦的《晴天》做成评论卡片

第一次运行时它会先做环境检查，缺什么会说明用途并征求你同意。成品默认放在当前目录的 `qqmusic_cards/<歌名>/cards/` 下。

## 目录结构

```
skills/qqmusic-comment-card/
├── SKILL.md                   # Agent 读取的主文件：流程、规则、停止条件
├── requirements.txt           # 依赖说明（由 install_deps.py 安装）
├── references/
│   ├── selection-rubric.md    # 怎样挑评论、排除什么、分组、截取
│   ├── layout-spec.md         # 版式数字、断行规则、可调参数、排障表
│   └── api-contract.md        # 库做了什么、字段、真实测试观察、数据里的"脏东西"
└── scripts/
    ├── check_environment.py   # 环境检查（只读）
    ├── install_deps.py        # 把第三方库装进 .deps（需先征得同意）
    ├── qq_fetch.py            # 搜歌、取封面、取热门评论、歌词比对
    ├── prepare_comments.py    # 量条数、打标记、截取片段、去重、打包建议
    ├── render_card.py         # 渲染卡片
    ├── qa_check.py            # 逐字比对与版面质检
    └── cardlib.py             # 共享工具
```
