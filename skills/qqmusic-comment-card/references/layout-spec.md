# 版式规范与排障

## 目录
- 默认版式
- 主图
- 字幕条与断行
- 字体
- 可调参数
- 排障：症状 → 调哪个变量

## 默认版式

- 画布 3:4，默认 1440×1920（`--width` 改宽度，`--aspect` 改比例）。
- 每条字幕条高度 = 画布高 × 7.5%（1920 高时为 144px），条间距为 0。
- 默认 4 条字幕条，主图占 `1 − 4 × 7.5% = 70%`（1344px）。与参考的视频字幕拼图 skill 一致。
- 每条字幕条只放**一行**文字。

## 主图

由下往上叠三层：

1. **背景**：封面铺满主图区域，缩小后做高斯模糊再放大（模糊半径约宽度的 7%），压暗 40%。
2. **封面**：保持原比例，不拉伸，居中，高度约为主图的 80%（`--cover-ratio` 调整）。专辑封面通常是正方形，
   1344px 高的主图里大约放 1075×1075；原图 1477×1477 时几乎不需要放大，清晰度很好。带柔和投影。
3. **署名**：封面下方两行：`《歌名》`，以及 `歌手 · QQ音乐热评`。**不显示评论者的任何信息。**

没有封面时，退化为深色渐变背景加大字歌名，仍然可以出图，但要告诉用户。

## 字幕条与断行

- 底色：从封面提取主色，压成明度很低的深色（保留色相；封面接近灰色时保持中性）。相邻两条明暗差约 14%，
  条顶有一条细暗线，帮助眼睛分出每一条，同时保持"零间距"的观感。
- 文字：白色，黑色描边，按墨迹居中。同一张卡里所有字幕条用同一个字号 = 能让最宽一行放下的最大字号，
  范围是条高的 36%–44%（1920 高时约 52–63px）。一行最多大约 25 个汉字。
- **断行规则**（`plan_comment`）：
  1. 评论里作者写的换行（包括被转义成字面 `\n` 的）直接当作字幕条的断行，每个换行段占 1 条；
  2. 某一段太长时再拆成 2 条，优先在标点后断，其次在"的/了"后或"在/把/但"前断，避免把"的/了/着"留在行首；
  3. 整条评论最多占 `--max-bands-per-quote` 条（默认 4，即整张卡）。
- 评论里的空格（作者用来停顿）原样保留，一个字幕条里会出现小间隔，这是作者的节奏。

## 字体

按顺序自动查找（`cardlib._font_candidates`）：Windows 微软雅黑粗体 → 微软雅黑 → 等线粗体 → 黑体 → 宋体；
macOS 苹方 → 华文黑体 → 冬青黑体；Linux Noto Sans CJK → 文泉驿。
指定字体用 `--font 路径`，或环境变量 `QQCARD_FONT`。指定的字体不存在会直接报错，不会悄悄换。
字体没有 emoji 字形，所以取数时就去掉了表情符号；其他缺字会在候选表里标"字体缺字"。

## 可调参数

| 参数 | 默认 | 作用 |
|---|---|---|
| `--width` | 1440 | 画布宽度，高度按比例算 |
| `--aspect` | 3:4 | 画布比例，如 4:5 |
| `--bands` | 4 | 每张卡的字幕条数（`prepare_comments.py` 和 `render_card.py` 要一致） |
| `--flex` | 关 | 允许每张卡 3–6 条，主图占比随之变化 |
| `--max-bands-per-quote`（prepare） | 4 | 单条评论最多占几条字幕条 |
| `--cover-ratio` | 0.80 | 封面占主图高度的比例 |
| `--cover` | 无 | 手动指定封面图，覆盖 `song.json` 里的封面 |
| `--font` | 自动 | 指定字体文件 |
| `--format` | jpg | `png` 文字边缘更锐利，文件更大 |
| `--overwrite` | 关 | 允许覆盖已有成品；默认拒绝覆盖 |

## 排障：症状 → 调哪个变量

| 症状 | 原因 | 处理 |
|---|---|---|
| 渲染前报"共占 N 条，需要正好 4 条" | 所选评论的条数加起来不是 4 | 换一条凑满；或用 `--flex` 允许 3–6 条 |
| 渲染前报"太长放不下" | 这条评论超过候选整理时设的条数上限 | 改用它的截取片段（如 `2.2`），或放弃这条 |
| 一句话在词中间断开 | 没有标点或换行可断 | 换一条；或取它的截取片段 |
| 字幕条文字偏小 | 同卡里有一行很满，拉低了全卡字号 | 换掉最长的那一条，让各行长度接近 |
| 缺字（方框） | 字体没有这个字 | 换字体（`--font`） |
| 封面发糊，QA 提示放大倍数高 | 封面原图小 | 调低 `--cover-ratio`；用 `--cover` 换更大的封面 |
| 卡面和评论原文不完全一样 | 取数时去掉了表情符号等 | 正常；交付时告诉用户 |
| 提示文件已存在 | 默认不覆盖 | 确认要替换再加 `--overwrite`，或换 `--out-dir` |

## 返工纪律

发现问题时只改对应的那一个变量，改完重跑渲染和质检。连续三轮仍不满意，换一组评论，
或者如实告诉用户限制在哪里，不要无限微调。
